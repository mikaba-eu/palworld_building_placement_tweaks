# Changelog

## 1.0.4

- Rebuilt every platform package from current Palworld 1.0.3 data.
- Preserved the updated material costs for the Large Power Generator, Crude
  Oil Extractor, and Advanced Crude Oil Extractor.

## 1.0.3

- Added flexible placement for the Fishing Pond and Large Fishing Pond.
- Rebuilt the Windows Dedicated Server package for Palworld server build
  `24575149`.

## 1.0.2

- Fixed the limit message that appeared before placing another Pal Expedition
  Station in a Base.

## 1.0.1

- Changed the expanded Pal Expedition Station capacity from a zero value to an
  explicit high per-Base maximum.
- Added flexible overlapping placement for the Stone Fence.

## 1.0.0

- Initial public release of Building Placement Tweaks.
- Added flexible placement for the supported structures, decorations, lights,
  workstations, and Base facilities.
- Added expanded terrain, vertical, floating, and building-capacity freedom.
- Added support for any number of Pal Expedition Stations in each Base.
- Added matching Windows client, Windows Dedicated Server, and Linux Dedicated
  Server packages.
